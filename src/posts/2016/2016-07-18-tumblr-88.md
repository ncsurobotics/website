*Testing New Software:*

With SeaWolf set to ship, the software team took one last pool test as time to test some brand new code allowing for the robot to now complete additional tasks along with being able to navigate the hedge challenge with style!

The acoustics team also spent a lot of time testing the robot’s ability to find the pinger in the water and follow it to the desired destination. All these tests provided promising results leaving the team just a few more things to work on before heading to competition.
