*Electrical:*

Seawolf VI’s electronics system was completely redesigned this year to be more modular and better fit the team’s need. Seawolf VI now features an array of six circuit boards each with a key function that contributes to overall electrical system.  

Additionally, the robot now has a dedicated power board that connects up to two 24V lithium polymer batteries in parallel, as well as provide telemetry to the main computer about how much charge is left in the batteries.

A new sensor board features a larger array of connectors allowing for a various selection of sensors to be added to Seawolf’s arsenal. 

Acoustics has also been redesigned to now include a custom designed four channel analog circuit mounted onto a BeagleBone Black.
