July 22nd:

Another early day began with the team’s new acoustics system being added to SeaWolf VI for the first run.  Unfortunately, this new system ended up draining the robot’s batteries more quickly than expected causing the robot to shut off after a few seconds of mission code testing. Luckily, the electrical team had a back up plan to switch the acoustics board to run separately using a 9V battery.

[You can read more about SeaWolf VI’s acoustics system here.](http://www.builtwithwires.com/beaglebone-black-underwater-acoustics-system-part-2/)

The day continued with more testing in all areas of the pool.  After the team’s third test a small leak was discovered that allowed some water to gather below the battery board in the hull.  No problems seemed to result from this mishap and SeaWolf was safely dried out, ready to run again.

The team has other minor repairs to make before hopefully hitting the pool tonight and returning for the final practice day tomorrow.
